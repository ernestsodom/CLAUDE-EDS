# 🚀 Configuración de Supabase

## ¿Qué es Supabase?

Supabase es una alternativa de código abierto a Firebase que proporciona:
- ✅ **Base de datos PostgreSQL** gratis
- ✅ **Autenticación** de usuarios
- ✅ **Almacenamiento** de archivos
- ✅ **Realtime** (actualizaciones en vivo)
- ✅ **API REST** automática

## Uso Básico

### 1. Conectarse a Supabase

```python
from supabase_client import get_supabase_client

client = get_supabase_client()
```

### 2. Crear una tabla (desde el dashboard)

1. Ve a [supabase.com](https://supabase.com) → tu proyecto
2. SQL Editor → New Query
3. Copia y ejecuta:

```sql
CREATE TABLE usuarios (
  id BIGINT PRIMARY KEY GENERATED BY DEFAULT AS IDENTITY,
  nombre TEXT NOT NULL,
  email TEXT UNIQUE NOT NULL,
  created_at TIMESTAMP DEFAULT NOW()
);
```

### 3. Insertar datos

```python
from supabase_client import get_supabase_client

client = get_supabase_client()

# Insertar un registro
response = client.table('usuarios').insert({
    'nombre': 'Juan',
    'email': 'juan@example.com'
}).execute()

print(response.data)
```

### 4. Consultar datos

```python
# Obtener todos los usuarios
data = client.table('usuarios').select('*').execute()
print(data.data)

# Con filtro
data = client.table('usuarios').select('*').eq('nombre', 'Juan').execute()
print(data.data)

# Limitar resultados
data = client.table('usuarios').select('*').limit(10).execute()
```

### 5. Actualizar datos

```python
response = client.table('usuarios').update({
    'nombre': 'Juan Pérez'
}).eq('email', 'juan@example.com').execute()
```

### 6. Eliminar datos

```python
response = client.table('usuarios').delete().eq('email', 'juan@example.com').execute()
```

## Migración desde SQLite

Si tienes datos en SQLite que quieres pasar a Supabase:

```python
import sqlite3
from supabase_client import get_supabase_client

# Conectar a SQLite
sqlite_conn = sqlite3.connect('database.db')
sqlite_conn.row_factory = sqlite3.Row
cursor = sqlite_conn.cursor()

# Obtener datos
cursor.execute("SELECT * FROM usuarios")
usuarios = cursor.fetchall()

# Insertar en Supabase
client = get_supabase_client()
for usuario in usuarios:
    client.table('usuarios').insert(dict(usuario)).execute()

print(f"✅ {len(usuarios)} registros migrados")
```

## Seguridad

⚠️ **IMPORTANTE:**
- La clave `SUPABASE_KEY` en `.env.example` es la clave **pública** (anon key)
- Es seguro usarla en el frontend
- Para operaciones de administración, usa `SUPABASE_SERVICE_KEY` en variables de entorno del servidor
